KRYTYCZNY PROBLEM ZIDENTYFIKOWANY: /health zwraca 404 (×10 requestów), /api zwraca 404 (862ms). Przyczyna: błędna kolejność middleware w backend/src/index.ts.
Problem — Błędna kolejność
// ❌ BŁĘDNA KOLEJNOŚĆ (aktualny index.ts) app.use('/api', router); // router podpięty app.use(notFoundHandler); // catch-all // /health NIE ISTNIEJE → 404! // /api może nie działać jeśli router pusty // Lub: routes zarejestrowane PO catch-all app.use((req, res) => res.status(404).json({...})); app.get('/health', handler); // ← NIGDY nie dotrze!
Fix — Poprawna kolejność
// ✅ POPRAWNA KOLEJNOŚĆ (GRAZYNA_BACKEND_FIX.ts) app.use(helmet()); app.use(cors({ origin: [':5173',':5174'] })); app.use(express.json()); // 1. Health PRZED routerami app.get('/health', healthHandler); // ← TUTAJ app.get('/metrics', metricsHandler); // ← TUTAJ // 2. API router app.use('/api', router); // ← TUTAJ // 3. Catch-all NA KOŃCU app.use(notFoundHandler); // ← NA KOŃCU!
